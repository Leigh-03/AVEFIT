# Contributing

Thanks for helping improve Workout Guide.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run check` before opening a pull request.
3. Include attribution and source-license details for every contributed asset.
4. Keep each exercise at exactly three transparent 512 × 512 SVG frames and their PNG sources.

By contributing code, you agree to license it under MIT. By contributing
visual assets, you agree to license them under CC BY-SA 4.0.
